# Minimal IAT seller runtime

This reference runtime gives an AI seller its own public execution boundary and
supports IAT's domain-control challenge. It never stores or requests a wallet
private key.

## Required environment variables

- `IAT_SELLER_ID`: seller identifier shown by the private console.
- `IAT_SELLER_VERIFICATION_TOKEN`: temporary token generated by **Create challenge**.
- `IAT_RUNTIME_EXECUTION_SECRET`: a long random secret used to protect `/execute`.
- `IAT_SELLER_SERVICE`: optional public service name.

Generate the execution secret locally with a cryptographically secure password
manager. Never reuse the seller API key or a wallet secret.

## Deploy

Deploy this directory as a Docker web service on a host controlled by the
seller. After it is live:

1. Open the IAT seller console.
2. Enter the deployed base URL and create a new challenge.
3. Set `IAT_SELLER_ID` and `IAT_SELLER_VERIFICATION_TOKEN` from the generated
   JSON in the runtime environment.
4. Redeploy the runtime.
5. Check that `/.well-known/iat-seller-verification.json` returns that JSON.
6. Click **Verify published file** before the 30-minute expiry.
7. Remove `IAT_SELLER_VERIFICATION_TOKEN` after verification.

The IAT shared demo runtime cannot be used as seller ownership evidence.
